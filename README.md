# 📊 Inflation vs Household Spending Analysis

## 📌 Overview
This project analyzes the relationship between inflation and household spending patterns using real-world data. The goal is to understand how rising inflation impacts consumer expenses across different categories.

## 🎯 Objectives
- Analyze trends in inflation over time  
- Examine changes in household spending  
- Identify correlation between inflation rates and spending behavior  
- Generate insights for economic and financial decision-making  

## 📁 Dataset
- Source: CSV file containing inflation rates and household spending data  
- Features may include:
  - Year / Month
  - Inflation Rate (%)
  - Total Household Spending
  - Category-wise spending (Food, Housing, Transport, etc.)

## 🛠️ Tech Stack
- Python (Pandas, NumPy)
- Data Visualization (Matplotlib / Seaborn / Power BI if used)
- Jupyter Notebook / VS Code

## 📊 Analysis Performed
- Data cleaning and preprocessing  
- Trend analysis of inflation and spending  
- Correlation analysis between inflation and expenses  
- Visualization of spending patterns across categories  

## 📈 Key Insights
- Increase in inflation shows a direct/indirect impact on essential spending categories  
- Certain categories (e.g., food, housing) are more sensitive to inflation changes  
- Household spending behavior adapts based on economic conditions
